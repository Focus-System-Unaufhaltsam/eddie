1. Hosting

This website is hosted with GitHub Pages. When the site is accessed, technical access data may be processed, including IP address, browser information and access time.

2. Firebase / Leaderboard

The global ranking uses Google Firebase / Firestore. When you save a rank, the display name, selected platform, social handle, score, play time, technical session data and timestamp are stored. Firebase Anonymous Authentication is also used to restrict write access to the ranking.

3. LocalStorage

The game stores your local best score in browser LocalStorage. This information stays on your device until you delete browser data or remove the storage manually.

Links to external platforms lead to websites outside this offer. Their own privacy terms apply.
