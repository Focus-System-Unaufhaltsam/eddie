Datenschutz

Betreiber der Website: Kevin Schulze (siehe Impressum).

1. Hosting

Diese Website wird über GitHub Pages bereitgestellt. Beim Aufruf der Website können technische Zugriffsdaten verarbeitet werden, zum Beispiel IP-Adresse, Browser-Informationen und Zeitpunkt des Abrufs.

2. Firebase / Leaderboard

Für das globale Ranking wird Google Firebase / Firestore genutzt. Wenn du einen Rang speicherst, werden der eingegebene Name, Score, Spielzeit, technische Sitzungsdaten und ein Zeitstempel gespeichert. Zusätzlich nutzt das Spiel Firebase Anonymous Authentication, damit Schreibzugriffe auf das Ranking eingeschränkt werden können.

3. LocalStorage

Das Spiel speichert deinen lokalen Bestwert im Browser-LocalStorage. Diese Information bleibt auf deinem Gerät, bis du Browserdaten löschst oder den Speicher manuell entfernst.

4. Externe Links

Links zu externen Plattformen führen auf Websites außerhalb dieses Angebots. Dort gelten die jeweiligen Datenschutzbestimmungen der Anbieter.

5. Kontakt und Rechte

Du kannst Auskunft, Berichtigung oder Löschung personenbezogener Daten anfordern. Kontakt: eddiekeschflow@gmail.com.
